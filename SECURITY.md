# Security policy

## Supported versions

Security fixes are applied to the latest commit on `main`. Older snapshots are not maintained separately.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's [private vulnerability reporting](https://github.com/emirhancaman/TimeTable/security/advisories/new) and include:

- the affected version or commit;
- reproduction steps or a proof of concept;
- the expected impact;
- any suggested mitigation.

You should receive an acknowledgement within seven days. Please allow time for investigation and a coordinated fix before public disclosure.

## Data and privacy scope

TimeTable stores planner data locally with Hive. Reports involving device storage, unintended data exposure, dependency vulnerabilities, or native widget data are in scope.
